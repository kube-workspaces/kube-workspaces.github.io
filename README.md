# Kube Workspaces

Browser-accessible development environments running as pods in your Kubernetes cluster. Open source, no database required.

This repository hosts the [Kube Workspaces](https://kubeworkspaces.io) website.

## Overview

Cloud-native workspace platform for Kubernetes:

- Browser-based dev environments
- Web UI with optional OIDC auth (Dex, Google, Okta, Auth0, or any OIDC provider)
- Reverse proxy, no database required
- Deploy with Helm, Kustomize, or ArgoCD
- Images published to `ghcr.io/kube-workspaces/*`

## Getting Started

Visit the live site at [kubeworkspaces.io](https://kubeworkspaces.io) or the quickstart section for install instructions.
